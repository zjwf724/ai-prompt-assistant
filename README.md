# AI Prompt Assistant

一个浏览器扩展，帮助您在主流AI聊天网站上快速管理和插入预设提示词。

## 🎯 核心功能

### ✅ 已实现功能
- **提示词管理**：支持分类存储、添加、删除提示词
- **快速插入**：在AI网站输入框旁显示图标，点击快速插入提示词
- **多平台支持**：支持8个主流AI平台（ChatGPT、Claude、Gemini等）
- **网站自定义管理**：可启用/禁用支持的网站，或添加自定义网站
- **数据持久化**：使用Chrome本地存储保存用户数据
- **导入导出**：支持JSON格式的提示词导入导出
- **响应式设计**：适配不同屏幕尺寸和暗色主题

### 🆕 新增：支持网站自定义删减

现在您可以完全控制插件在哪些网站上工作：

#### 1. 网站管理界面
- 查看所有支持的AI网站
- 启用/禁用特定网站（使用切换开关）
- 删除不需要的网站
- 添加自定义AI网站

#### 2. 网站管理操作
- **启用/禁用**：点击切换开关可快速启用或禁用网站
- **删除网站**：点击×按钮删除网站
- **添加自定义网站**：支持添加任何AI聊天网站
- **重置默认**：一键恢复所有默认网站配置

#### 3. 动态检测机制
- 插件只在启用的网站上激活
- 内容脚本会检查当前网站是否在启用列表中
- 后台服务动态管理网站注入规则

## 🚀 使用方法

### 安装扩展
1. 打开Chrome扩展管理页面 (`chrome://extensions/`)
2. 开启"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择 `ai-prompt-assistant` 文件夹

### 配置支持网站
1. 点击浏览器工具栏的插件图标
2. 滚动到"支持网站管理"部分
3. 使用切换开关启用/禁用网站
4. 或点击"+ 添加自定义网站"添加新网站

### 管理提示词
1. 点击"添加提示词"按钮
2. 选择或输入分类名称
3. 填写标题和内容
4. 点击"保存"

### 在AI网站使用
1. 访问任何启用的AI网站
2. 点击输入框右下角的绿色图标
3. 选择要插入的提示词
4. 提示词会自动插入到输入框中

## 🔧 技术架构

### 文件结构

├── background.js       # 后台服务（数据管理）

├── popup.js            # 弹出窗口逻辑
└── styles.css          # 所有样式

### 数据存储结构
```javascript
{
  "prompts": {
    "角色扮演": [
      { "title": "专业翻译", "content": "请扮演..." }
    ]
  },
  "settings": {
    "showIcon": true,
    "autoDetect": true,
    "theme": "auto"
  },
  "aiSites": [
    { "name": "ChatGPT", "hostname": "chatgpt.com", "enabled": true }
  ]
}
```

## ⚠️ 注意事项

1. **权限说明**：
   - `storage`：存储提示词和配置
   - `activeTab`：获取当前标签页
   - `scripting`：注入内容脚本

2. **域名格式**：
   - 添加自定义网站时，只需输入域名（如：`myai.com`）
   - 不需要 `http://` 或 `https://` 前缀
   - 不需要路径部分

3. **生效时机**：
   - 网站配置修改后立即生效
   - 需要刷新已打开的AI网站页面
   - 新配置会在下次访问时应用

## 🔒 安全性

- ✅ 无网络请求，数据仅存储在本地
- ✅ 不收集任何用户数据
- ✅ 不访问除配置域名外的任何网站
- ✅ 开源代码，可审查

## 🐛 已知问题

- 部分AI网站可能使用动态加载，需要等待页面完全加载
- 某些网站的输入框可能需要手动点击图标触发
